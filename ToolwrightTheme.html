A design system for Toolwright and UAssist docs

ToolwrightTheme combines two surfaces: a bright article mode for long-form help and tutorials, and a dark editor mode for the tool UI. Both share the same type scale, spacing, and component vocabulary. The theme responds to prefers-color-scheme.

Light article mode Dark editor mode Auto switching

Principles

Article first. Documentation is read like a book, not operated like a dashboard. The body is single-column, generous, and low-contrast enough to read for minutes.
Editor when it matters. The dark mode keeps the same components but swaps to high-contrast panels, borders, and accent colours so tools remain readable under long use.
One vocabulary. The same pill, queue, table, mock, and code styles work in both modes; only the colour values change.

Colour palette

The theme uses semantic variables that swap in dark mode. Hard-coded colour values should almost never appear in content CSS.

Lead — 18 px serif, slightly muted, for introductions.

CSS tokens

Copy the :root block into any UAssist or Toolwright page to adopt the theme. Add the media query to support dark mode.

:root {
  --bg: #f8f9fb;
  --surface: #ffffff;
  --surface-2: #f3f5f7;
  --fg: #111827;
  --fg-strong: #030712;
  --muted: #4b5563;
  --faint: #9ca3af;
  --line: #e2e5e9;
  --line-strong: #d1d5db;
  --border: #d1d5db;
  --accent: #0ea5e9;
  --accent-text: #0284c7;
  --ok: #16a34a;
  --warn: #d97706;
  --bad: #dc2626;

  --font-sans: 'Archivo', system-ui, sans-serif;
  --font-serif: 'Merriweather', Georgia, serif;
  --font-mono: 'JetBrains Mono', ui-monospace, monospace;

  --measure: 680px;
  --wide: 960px;
  --radius: 6px;
}
